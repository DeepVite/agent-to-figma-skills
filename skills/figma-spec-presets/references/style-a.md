# Style A — 暖橙通用精简风（v1.1）

适用场景：通用产品文档、数据看板、轻量原型说明、沿用暖橙系的已有文档页、需要紧凑高密度排版的画布。

---

## 1. 字体与字重

- **字体族**：拉丁与数字 `Inter`；中文回退 `PingFang SC` / 微软雅黑（确保字体在当前 Figma 环境可用）。
- **字重**：`Regular 400`（正文/表格）、`Medium 500`（表头/轻强调）、`SemiBold 600`（标题）、`Bold 700`（大标题/指标数字）。

## 2. 字号阶梯（10 级）

| 样式名 | 字号 / 字重 / 行高 | 色值 | 适用场景 |
|---|---|---|---|
| `Text/Display` | `40px` / Bold 700 / `48px` | `#262626` | 封面、大屏主标题 |
| `Text/H1` | `32px` / SemiBold 600 / `40px` | `#262626` | 页面主标题 |
| `Text/H2` | `24px` / SemiBold 600 / `32px` | `#262626` | 模块 / 区块标题 |
| `Text/H3` | `18px` / SemiBold 600 / `24px` | `#262626` | 卡片 / 分区标题 |
| `Text/H4` | `16px` / SemiBold 600 / `24px` | `#262626` | 表单 / 小节标题 |
| `Text/Body-L` | `14px` / Regular 400 / `22px` | `#595959` | 长段落 / 引导语 |
| `Text/Body` | `13px` / Regular 400 / `20px` | `#595959` | 默认正文 / 说明 |
| `Text/Body-S` | `12px` / Regular 400 / `20px` | `#595959` | 表格 / 辅助信息 |

| `Text/Data` | `28px` / Bold 700 / `32px` | `#D07A16` | 指标 / 统计数字 |

## 3. 色彩体系（附 0–1 RGBA 换算参考）

- **画布与容器**：
  - 画布底色 `#F5F6F8` (`0.961, 0.965, 0.973`)
  - 卡片底色 `#FFFFFF` (`1, 1, 1`)，无描边，圆角 `10–12px`
  - 斑马纹 `#FBFBFC` (`0.984, 0.984, 0.988`)
  - 分割线 `#F0F0F0` (`0.941, 0.941, 0.941`)
- **文字层级**（禁止纯黑 `#000000`）：
  - 主文字 `#262626` (`0.149, 0.149, 0.149`)
  - 次文字 `#595959` (`0.349, 0.349, 0.349`)
  - 弱化文字 `#8C8C8C` (`0.549, 0.549, 0.549`)
- **品牌与语义**：
  - 品牌主色 `#D07A16` (`0.816, 0.478, 0.086`)
  - 品牌亮色 `#FA8C16` (`0.980, 0.549, 0.086`)
  - 章节竖条 `#F0A64F` (`0.941, 0.651, 0.310`)
  - 浅橙提示底 `#FFF7E6` (`1, 0.969, 0.902`)
  - 成功 `#52C41A` (`0.322, 0.769, 0.102`)
  - 警告 `#FAAD14` (`0.980, 0.678, 0.078`)
  - 错误 `#FF4D4F` (`1, 0.302, 0.310`)

## 4. 关键排版与布局规则

- 顶部加 `6px` 暖橙装饰条（`#FA8C16`），章节标题左侧配 `4×16px` 暖橙竖条（`#F0A64F`）。
- 同一屏内字号层级 `<= 4` 级、字重 `<= 2` 种、正文颜色 `<= 3` 种。
- 优先使用 `VERTICAL` / `HORIZONTAL` Auto-Layout Frame 搭建卡片与行表，保持内边距（`20–24px`）与区块间距（`20–28px`）统一。
