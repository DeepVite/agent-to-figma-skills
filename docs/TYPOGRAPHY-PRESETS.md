# Figma 文档与原型说明文本样式预设（样式 A / 样式 B）

> 本预设集已从底层连通仓 [`agent-to-figma`](https://github.com/DeepVite/agent-to-figma) 拆出，作为独立、**可选（Opt-in）** 的视觉规范沉淀在 `agent-to-figma-skills` 中。对应 Agent Skill 见 [`skills/figma-spec-presets/SKILL.md`](../skills/figma-spec-presets/SKILL.md)。

在 Figma 或 OpenFigma 画布中编写产品文档、数据看板或原型说明时，如果你希望复用稳定的排版与视觉 Token，可以按场景自由选择以下两套预设之一；无需预设或需要自由创作时，直接让 Agent 自主设计即可。

---

## 快速选型对照

| 维度 | 样式 A · 暖橙通用精简风 | 样式 B · 靛蓝原型说明系统 |
|---|---|---|
| **定位** | 通用产品文档、数据看板、轻量原型说明 | 专用于原型旁白、PRD 模块拆解、交互与异常边界标注 |
| **视觉气质** | 暖橙强调 + 中性灰，接近 Ant Design 经典风格 | 深色编辑风头图 + 冷调靛蓝说明层，与产品 UI 清晰隔离 |
| **画布 / 卡片** | `#F5F6F8` 画布 + `#FFFFFF` 无描边圆角卡 | `#F8FAFC` 画布 + `#FFFFFF` `1px #E2E8F0` 细描边圆角卡 |
| **正文与底线字号** | 正文 `13px/20px` · 最小注释 `11px/16px` | 正文 **`14px/22px`** · **最小底线 `12px/18px`**（适合 50% 缩放巡检） |
| **文字对比度** | `#262626` / `#595959` / `#8C8C8C` | `#0F172A` / `#334155` / `#64748B`（全级达 WCAG AA/AAA） |
| **语义配色** | 单色色块（成功/警告/错误） | **主色 + 浅底 + 边框** 完整三元组，适配胶囊与提示块 |
| **原型专用组件** | 基础卡片与表格 | 标点锚定项（Pin Callout）、四类提示块（Callouts）、状态/优先级标签、异常兜底表 |
| **布局实现** | 简洁卡片与行表 | 100% 嵌套 Auto-Layout Frame，可直接 Alt 拖拽复用 |
| **推荐场景** | 已有旧页沿用暖橙系、追求紧凑高密度文本 | 新建原型旁白、多人评审、需要和产品 UI 色彩隔离 |

## 样式 A · 暖橙通用精简风（Style A）

完整规格（含 `0–1` RGBA 换算值）见 [`skills/figma-spec-presets/references/style-a.md`](../skills/figma-spec-presets/references/style-a.md)。

### 1. 字体与字重

- **字体族**：拉丁与数字 `Inter`；中文系统字体回退（`PingFang SC` / 微软雅黑）。
- **字重**：`Regular 400`（正文/表格）、`Medium 500`（表头/轻强调）、`SemiBold 600`（标题）、`Bold 700`（大标题/数据）。

### 2. 字号阶梯（10 级）

| 样式名 | 字号 / 字重 / 行高 | 色值 | 适用场景 |
|---|---|---|---|
| `Display` | `40px` / Bold 700 / `48px` | `#262626` | 封面、大屏主标题 |
| `H1` | `32px` / SemiBold 600 / `40px` | `#262626` | 页面主标题 |
| `H2` | `24px` / SemiBold 600 / `32px` | `#262626` | 模块 / 区块标题 |
| `H3` | `18px` / SemiBold 600 / `24px` | `#262626` | 卡片 / 分区标题 |
| `H4` | `16px` / SemiBold 600 / `24px` | `#262626` | 表单 / 小节标题 |
| `Body-L` | `14px` / Regular 400 / `22px` | `#595959` | 长段落 / 引导语 |
| `Body` | `13px` / Regular 400 / `20px` | `#595959` | 默认正文 / 说明 |
| `Body-S` | `12px` / Regular 400 / `20px` | `#595959` | 表格 / 辅助信息 |
| `Caption` | `11px` / Regular 400 / `16px` | `#8C8C8C` | 时间 / 来源 / 标签 |
| `Data` | `28px` / Bold 700 / `32px` | `#D07A16` | 指标 / 统计数字 |

### 3. 色彩体系

- **画布与容器**：画布 `#F5F6F8` · 卡片 `#FFFFFF` · 斑马纹 `#FBFBFC` · 分割线 `#F0F0F0`
- **文字层级**：主文字 `#262626` · 次文字 `#595959` · 弱化文字 `#8C8C8C`
- **品牌与语义**：品牌主色 `#D07A16` · 品牌亮色 `#FA8C16` · 浅橙提示底 `#FFF7E6` · 成功 `#52C41A` · 警告 `#FAAD14` · 错误 `#FF4D4F`

### 4. 关键规则

- 顶部 6px 暖橙装饰条（`#FA8C16`），章节标题左侧配 `4×16px` 暖橙竖条（`#F0A64F`）。
- 同一屏内字号层级 ≤ 4 级、字重 ≤ 2 种、正文颜色 ≤ 3 种；不使用纯黑 `#000000`。
- 命名建议：`Text/Display` · `Text/H1` · `Text/Body` · `Text/Caption` · `Text/Data`。

## 样式 B · 靛蓝原型说明系统（Style B）

完整规格（含 `0–1` RGBA 换算值与构件级 Auto-Layout 提示）见 [`skills/figma-spec-presets/references/style-b.md`](../skills/figma-spec-presets/references/style-b.md)。

### 1. 设计定位与字体规则

- **核心原则**：**说明层 ≠ 产品 UI 层**。用冷调靛蓝与 Slate 中性色区隔业务原型的品牌色，在 Figma 50%–100% 缩放巡检时保持高可读性。
- **字体族**：拉丁与数字 `Inter`；中文回退 `PingFang SC` / 微软雅黑；中英/数字间保留半角空格（如 `超过 500 字触发 Toast`）。
- **结构硬要求**：所有模块、表格行、标签、提示块、行内混排均使用**嵌套 Auto-Layout Frame**，禁止散落裸 `Rectangle` 与手工估算 X 坐标拼排。

### 2. 字号阶梯（9 级，底线 12px）

| Token 名称 | 字号 / 字重 / 行高 | 色值 | 适用场景 |
|---|---|---|---|
| `Spec / Display` | `30px` / Bold 700 / `38px` | `#0F172A` | 画布封面、大型需求总标题 |
| `Spec / H1` | `24px` / Bold 700 / `32px` | `#0F172A` | 页面级分区、主业务流程标题 |
| `Spec / H2` | `20px` / SemiBold 600 / `28px` | `#0F172A` | 原型旁白面板标题、功能块标题 |
| `Spec / H3` | `16px` / SemiBold 600 / `24px` | `#0F172A` | 编号标点标题、表格/表单小节 |
| `Spec / Body-L` | `15px` / Regular 400 / `24px` | `#334155` | 页面背景导语、重要结论说明 |
| `Spec / Body` | `14px` / Regular 400 / `22px` | `#334155` | 默认正文、交互步骤（主力） |
| `Spec / Body-S` | `13px` / Regular 400 / `20px` | `#334155` | 字段规则表、紧凑补充描述 |
| `Spec / Caption` | `12px` / Medium 500 / `18px` | `#64748B` | 表头、标签、时间戳（最小底线） |
| `Spec / Code` | `13px` / SemiBold 600 / `20px` | `#4F46E5` | 接口字段、埋点键名、状态枚举（配浅灰底片） |

### 3. 色彩与语义三元组（文字主色 / 浅底 / 边框）

- **头图与画布**：深色编辑风头图 `#0F172A`（内嵌元信息卡 `#1E293B` / 边框 `#334155`）· 画布 `#F8FAFC` · 卡片 `#FFFFFF`（描边 `1px #E2E8F0`）
- **中性文字（WCAG AA/AAA）**：`Ink/Primary` `#0F172A` · `Ink/Body` `#334155` · `Ink/Muted` `#64748B` · `Ink/Subtle` `#94A3B8`
- **语义三元组**：
  - `Spec / Brand`（标点 / 链接）：主色 `#4F46E5` · 浅底 `#EEF2FF` · 边框 `#C7D2FE`
  - `Status / Added`（已定稿 / 新增）：主色 `#047857` · 浅底 `#ECFDF5` · 边框 `#A7F3D0`
  - `Status / Edge`（待确认 / 边界）：主色 `#B45309` · 浅底 `#FFFBEB` · 边框 `#FDE68A`
  - `Status / Block`（废弃 / 阻断）：主色 `#BE123C` · 浅底 `#FFF1F2` · 边框 `#FECDD3`
  - `Tech / API`（接口 / 埋点）：主色 `#0369A1` · 浅底 `#F0F9FF` · 边框 `#BAE6FD`

### 4. 阅读节奏与原型专用组件

- **空间与行宽**：最佳行宽 **`360–520px`**（单行 25–36 汉字）；段落间距 `12px`、标点条目间距 `16px`、模块间距 `32–48px`；说明卡片与原型图右缘保持 **`48–64px`** 安全间距。
- **4 套专用说明构件**：
  1. **编号标点说明项（`Spec/Comp/Pin`）**：圆形靛蓝标点 `01`/`02`/`03`（`26×26`，白字 Bold）+ 标题 + 状态标签 + 交互规则，与原型图上的编号锚点一一对应。
  2. **四类语义提示块（`Spec/Comp/Callout`）**：左侧 `4px` 通高语义色条 + 浅底框（`说明 Info` / `新增 Added` / `边界 Warn` / `废弃 Block`）。
  3. **优先级 / 状态 / 端别标签（`Spec/Comp/Badge`）**：HUG 胶囊（`P0 必做`、`已定稿`、`v2.0 新增`、`iOS / Android`、`仅服务端`）。
  4. **状态与异常兜底表（`Spec/Comp/Table`）**：圆角描边表格，列固定对齐，至少覆盖「正常态 / 空态 / 异常超时兜底」。

## 如何按需启用

仅在需要复用上述风格时，向 Agent 显式点名即可（无需在所有 Figma 任务中强行套用）：

```text
# 指定样式 A
请使用 figma-spec-presets 的「样式 A（暖橙通用精简风）」，在新页面写入本次产品说明。

# 指定样式 B
请使用 figma-spec-presets 的「样式 B（靛蓝原型说明系统）」，在新页面写入本次原型说明，并配齐编号标点与边界提示块。
```
